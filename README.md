# Giftified.pk

Mobile-first print-on-demand store for Pakistan (mugs, t-shirts, hoodies · Cash on Delivery).

```bash
pnpm install
pnpm dev            # http://localhost:3000  → /design/mug
pnpm check          # lint + typecheck + unit tests
pnpm build && pnpm e2e
```

Project rules, architecture and conventions: see [CLAUDE.md](./CLAUDE.md).
Copy `.env.example` to `.env.local` before working on commerce/messaging.
